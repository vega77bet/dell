DELL / OS — AURORA 0.1

Seu computador.
Novas possibilidades.

Um espaço leve para criar, explorar e cuidar das suas coisas. Este guia funciona mesmo sem conexão.

Crie alguma coisa

Abra Texto para escrever, Paint para desenhar e Captura para gravar sua voz.

Encontre seu caminho

O menu Dell OS reúne seus aplicativos. Busque pelo nome para abrir rapidamente.

Deixe do seu jeito

Em Configurações, escolha o tema, wallpaper, rede, áudio e preferências do computador.

Primeiros passos

Conecte o Wi-Fi pelo ícone de rede na barra. Teste o som em Configurações → Som e microfone. Conecte um pendrive e procure em Arquivos → Dispositivos USB.

Instalar no notebook

Use o atalho Instalar Dell OS na área de trabalho da sessão Live. Faça uma cópia de seus arquivos antes. A opção Apagar disco remove o sistema e os arquivos existentes no disco selecionado. Revise o resumo e confirme o disco correto antes de instalar. Ao concluir, desligue, remova o pendrive e ligue novamente.

Atalhos para o dia a dia

Win + E Arquivos · Win + Enter Terminal · Alt + Tab Alternar janelas · Win + D Área de trabalho · Print Captura.

Um navegador leve começa com poucas abas

Com 3 GB de memória, mantenha poucas abas abertas e feche os aplicativos que não estiver usando. O Paint limita o tamanho das imagens e o histórico para ajudar no consumo de memória.

Recuperação básica

Se a interface não iniciar, tente a opção de vídeo seguro no menu do pendrive. Para recuperar arquivos, inicie a sessão Live, abra Arquivos e copie seus documentos para outro dispositivo. No sistema instalado, o menu GRUB também oferece as opções de recuperação do Debian.
